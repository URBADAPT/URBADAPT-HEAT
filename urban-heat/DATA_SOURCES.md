# Input data sources (four pilot cities)

One row per input dataset used by the Rome, Athens, Lisbon and Copenhagen runs. Paths are relative to `urban-heat/data/<City>/` unless marked *repo* (committed in this repository) or *runtime* (fetched by a notebook from the provider, not from Drive). Drive file ids are in `data_manifests/<city>_gdrive.json`. Licences were checked on the provider pages on 2026-11-12.

**Archive?** = may the original (or the clipped subset used here) go into a public input archive; the files marked yes that are not available elsewhere with a persistent identifier are in the v1.0.1 input record, doi:10.5281/zenodo.24163362. **Authors?** = produced by the URBADAPT-HEAT authors; these can be archived by the authors.

Licence notes for an input archive: the repository's CC0 dedication does not extend to third-party files (including `10288665/`), which keep their own licences; the OSM-derived files must be published under ODbL 1.0 and, if confirmed, the PROVIDE-derived deltas under CC BY-SA, so both belong in separately licensed parts of the archive; all CC BY sources need the attribution and change statement their providers ask for.

[^urbclim]: The daily files are downloaded by NB01 from the VITO server, not from the Copernicus Climate Data Store (CDS). The server page asks users to cite De Ridder et al. (2015, doi:10.1016/j.uclim.2015.01.001) and Souverijns et al. (2026) but states no licence, and the NetCDF global attributes (`title`, `institution`, `creator`, `source`) carry none. The CC BY 4.0 Zenodo record of the same project (doi:10.5281/zenodo.13361538) holds only decadal indicator maps, not these daily fields. The Copernicus C3S product "Climate variables for cities in Europe from 2008 to 2017" (doi:10.24381/cds.c6459d3a; CC BY 4.0 per its catalogue record) is also UrbClim at 100 m for 2008-2017 and includes Rome, Athens, Lisbon and Copenhagen, but it is hourly, is marked "Deprecated 10-05-2024" and its downloads are disabled; that the VITO daily files are aggregates of those C3S runs is not documented. To archive the daily fields, get written permission or a licence statement from VITO (urbclim@vito.be).

[^deltas]: The raw files are `https://provide.marvin.vito.be/ftp/future_deltas/<City>/<scenario>/<City>_<year>_<GCM>_ensmean.xlsx`. No licence is stated on the server. The files come from the PROVIDE project, whose Climate Risk Dashboard (now hosted by IIASA) puts "all text, figures and data" under CC BY-SA without giving a version; whether that also covers the files on the VITO server is not stated. If it does, the derived CSVs can be archived under CC BY-SA. The CSVs in the model folder are monthly city-mean deltas computed by the authors from those files.
